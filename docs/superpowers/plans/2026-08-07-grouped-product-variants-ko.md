# 묶음 상품 통합 계획 — 쉬운 한국어

## 한 줄 목표

관리자에서 `포스터`와 `전단지`를 따로 등록된 상품 2개로 보지 않고, **`포스터 · 전단지` 상품 1개 안에 들어 있는 두 가지 설정**으로 바꿉니다.

## 완성된 모습

관리자 목록에는 아래처럼 한 줄만 보입니다.

```text
포스터 · 전단지 | 게시 | 130,000원~ | 상세
```

상세 페이지에 들어가면 지금과 같은 버튼이 있습니다.

```text
[포스터] [전단지]
```

- `포스터` 버튼에서는 포스터의 크기·용지·코팅·가격을 입력합니다.
- `전단지` 버튼에서는 전단지의 크기·용지·단면/양면·가격을 입력합니다.
- 버튼을 오가도 작성 중인 내용은 사라지지 않습니다.
- 저장, 임시저장, 게시, 삭제는 `포스터 · 전단지` 전체에 한 번만 적용됩니다.

## 다른 묶음 상품도 똑같이 처리합니다

| 관리자 목록의 상품 1개 | 상세 페이지 안의 버튼 |
| ---------------------- | --------------------- |
| 브로슈어 · 카탈로그    | 별도 버튼 없음        |
| 리플렛 · 팜플렛        | 별도 버튼 없음        |
| 포스터 · 전단지        | 포스터 / 전단지       |
| 배너 · 족자 · 현수막   | 배너 / 족자 / 현수막  |
| 명함 · 봉투            | 명함 / 봉투           |
| 로고                   | 별도 버튼 없음        |

현재 관리자 데이터는 세부 설정 기준 10줄이지만, 작업 후에는 고객에게 보여주는 상품 기준과 같은 **6줄**이 됩니다.

## 가격 표시

한 상품 안에서 가장 낮은 가격을 찾아 `최저가~`로 보여줍니다.

예를 들어:

- 포스터 최저가: 520,000원
- 전단지 최저가: 130,000원
- 관리자 목록 표시: `130,000원~`

## 게시와 삭제

- 포스터만 먼저 게시하는 기능은 만들지 않습니다.
- 게시 버튼을 누르면 포스터와 전단지 입력을 모두 확인합니다.
- 둘 중 하나라도 필수 입력이 빠졌으면 게시되지 않습니다.
- 삭제하면 포스터와 전단지가 함께 삭제됩니다.
- 임시저장은 지금처럼 입력이 덜 끝난 상태에서도 가능합니다.

## 작업 순서

### 1. 기존 데이터 백업

현재 상품 10개의 ID, 옵션, 가격을 따로 안전하게 보관합니다. 실제 데이터가 맞지 않거나 포스터와 전단지의 게시 상태가 서로 다르면 합치지 않고 작업을 중단합니다.

### 2. DB에서 상품을 10개에서 6개로 합치기

각 묶음에서 기존 상품 ID 하나를 대표로 유지하고, 나머지 세부 상품의 옵션과 가격을 그 안으로 옮깁니다.

```text
변경 전
포스터 1줄 + 전단지 1줄

변경 후
포스터 · 전단지 1줄
└ 포스터 설정 + 전단지 설정
```

### 3. 관리자 상세 페이지 연결

현재 버튼 디자인은 그대로 사용합니다. 달라지는 점은 버튼을 누를 때 다른 상품을 불러오는 것이 아니라, 같은 상품 안의 다른 설정으로 전환된다는 것입니다.

### 4. 관리자 목록 정리

- 상품은 6줄만 표시합니다.
- 같은 상품명이 두 번 보이지 않도록 중복 컬럼을 정리합니다.
- 상태와 상세 버튼은 지금처럼 유지합니다.
- 가격 뒤에는 `~`를 붙입니다.

### 5. 테스트 후 배포 준비

개발용 DB에서 먼저 아래 내용을 확인합니다.

- 상품이 정확히 6개인지
- 기존 가격표와 견적 데이터가 하나도 사라지지 않았는지
- 상세 버튼을 오가도 입력값이 유지되는지
- 일부만 작성한 상태에서는 게시가 막히는지
- 전체 삭제와 순서 변경이 정상인지

확인이 끝나도 실제 DB 반영은 별도의 배포 승인 후 진행합니다.

## 이번 작업에서 하지 않는 것

- 사용자 주문 화면을 DB와 연결하지 않습니다.
- 사용자 화면의 `포스터 · 전단지` 카드 디자인을 바꾸지 않습니다.
- 포스터와 전단지를 따로 게시하거나 따로 삭제하는 기능을 만들지 않습니다.
- 관리자 상세 화면을 새로 디자인하지 않습니다.

## 최종 결과

사용자에게는 원래처럼 `포스터 · 전단지` 하나로 보이고, 관리자에게도 같은 기준으로 한 줄만 보입니다. 포스터와 전단지의 서로 다른 옵션과 가격은 사라지지 않고, 한 상품의 상세 페이지 안에서 각각 관리됩니다.
